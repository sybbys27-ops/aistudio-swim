<자유형 시뮬레이션 동작 원리>
- 자유형은 수면에 업드려서 수평뜨기를 하여 오른손/왼손으로 번갈아서 스트로크를 하며 앞으로 나아간다.
- 이것은 실제 자유형의 모습을 시뮬레이션 해보기 위한 것이다.


(1). 기본사항
1. 오른팔의 손은 빨간색, 왼팔의 손은 파란색으로 되어 있다.
2. 수영장의 길이는 50m이다.
3. 킥은 계속 움직이고 있다.
4. 출발하면 최저 속도 0.3m/s 된다.(발차기 기본 속도)


(2). 시뮬레이션 시작
1. 양손은 앞으로 뻗은 상태에서 시작한다.
2. 지정된 롤링 각도만큼 오른쪽 어깨가 회전되어 내려간 후 오른손으로 첫 스트로크가 시작된다.
3. 오른쪽 첫 스트로크의 시작은 로링각도(-)가 만들어지고 글라이딩 시간이 없이 출발한다.


(3). Parameter Controls

1. Rolling Angle
- 롤링은 정해진 각도만큼 왼쪽/오른쪽 어깨가 번갈아서 회전 됨
- 롤링 각도가 50도 라면, 오른쪽 어깨는 몸이 회전되면서 수면(수평)을 기준으로 -50도 내려 갔다가 +50도 오르기를 반복한다.
- 몸의 중심축으로 회전하므로 왼쪽어깨는 오른쪽 어깨의 반대로 움직인다.   

2. Rolling Time
- 1초~4초까지, 0.5초 간격으로 설정 
- 정해진 Rolling Angle 변환 되는 시간이다.
- Rolling Angle = 50도, Rolling interval=3초 라면,
한쪽의 어깨가 수면아래 -50도에서 시작해 수면위 +50도로 이동하는 시간은 3초가 된다.
- 몸의 회전인 롤링은 오른쪽 어깨가 -50도 일때, 왼쪽 어깨는 +50도가 되며 계속 +/-각도가 반복된다.

3. Glide Duration
- 0초~2초, 0.25초 간격으로 설정
- 정해진 롤링 각도에서 멈추어 유지되는 시간이다.

4. Stroke Time
- 한쪽 팔이 캐치-풀-푸시(피니쉬)-리커버리를 하여 앞으로 다시 돌아오는 시간이다. 
- Rolling Time(1초~4초) + Glide Duration(0초~2초)을 합친 시간이며
최소 1초, 최대 6초가 된다.

5. Stroke Interval
- 1초~ 6초, 0.25초 간격으로 설정
- 최대 시간이 Stroke Time을 초과할 수 없다.
- 5초로 지정했을 때, Stoke Time = 4초 라면 4초로 지정된다.

## 개발 설명

[설정]
- Rolling Time =3초, Glide Duration=1초 라면 Stroke Time = 4초가 된다.
- Stroke Time (한 팔 스크로크 지속 시간) = 4초
- Stroke Interval (오른팔과 왼팔의 출발 시간 간격) = 3.5초 
[타임라인 흐름]
1. T = 0.0초: 오른팔이 스트로크를 시작함 (4초간 지속되어 4.0초에 끝남).
2. T = 3.5초: 오른팔이 리커버리 중인 상태에서, 왼팔이 스트로크를 시작함 (4초간 지속되어 7.5초에 끝남).
   * 결과적으로 3.5초~4.0초 구간(0.5초 동안)은 양팔이 동시에 스트로크를 하는 오버랩(Overlap) 구간임.
3. T = 4.0초: 오른팔 스트로크가 종료되고, 앞으로 뻗은 대기(Gliding) 상태로 전환됨.
4. T = 7.0초 (3.5초 + 3.5초): 왼팔이 리커버리 중인 상태에서, 오른팔이 다시 두 번째 스트로크를 시작함.
5. T = 7.5초: 왼팔 스트로크가 종료되고, 앞으로 뻗은 대기(Gliding) 상태로 전환됨.
6. 이 주기가 3.5초 간격으로 오른팔->왼팔->오른팔->왼팔 무한 반복됨.


 6. Body pitch
- 나아가는 전면 방향에 대한 몸의 각도이다.
